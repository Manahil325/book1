# ROS 2 Robotic Nervous System Documentation

This documentation site explains ROS 2 as the core middleware enabling communication and control in humanoid robotics. It's designed for AI engineers and software developers entering Physical AI and robotics.

## Features

- Comprehensive guide to ROS 2 fundamentals
- Python agents with rclpy integration
- Humanoid modeling with URDF
- Practical examples and code snippets
- Technical accuracy and verifiability

## Installation

```bash
npm install
```

## Local Development

```bash
npm start
```

This command starts a local development server and opens up a browser window. Most changes are reflected live without having to restart the server.

## Build

```bash
npm run build
```

This command generates static content into the `build` directory and can be served using any static contents hosting service.

## Contributing

This project follows the ROS 2 documentation standards and best practices. All content is written to be accessible to AI engineers and software developers new to robotics.
